# 0.7.2 — 2026-09-22

## Fixed

- **`congressgov_roll_votes` Senate list rows** now carry a resolved `voteDateIso` beside the menu's year-less `voteDate`, derived by walking the session's vote sequence across December→January rollovers. ([#67](https://github.com/cyanheads/congressgov-mcp-server/issues/67))
- **`congressgov_bill_summaries` and `congressgov_bill_lookup` `summaries`** now bound page size and per-row summary text — a windowed row carries `textTotalCharacters`/`textTruncated`/`textNextOffset`, and `summaries` gains a `versionCode` selector. ([#70](https://github.com/cyanheads/congressgov-mcp-server/issues/70))

## Security

- **Character references** decode in a single pass through a shared decoder (`src/utils/character-references.ts`), replacing three ad-hoc `replace()` chains across document extraction, the search mirror, and tool formatting. Closes three CodeQL `js/double-escaping` alerts. ([#73](https://github.com/cyanheads/congressgov-mcp-server/issues/73))

## Dependencies

- `@types/node` `^26.6.1` → `^26.6.2`
