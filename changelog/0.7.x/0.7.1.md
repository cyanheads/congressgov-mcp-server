# 0.7.1 — 2026-09-19

## Changed

- **`@cyanheads/mcp-ts-core`** advances from `^0.12.3` to `^0.13.6`. Require Bun 1.4.0 or newer; development skills now live in `framework-skills/` rather than `skills/`.
- **HTTP sessions:** With `MCP_SESSION_MODE` unset, HTTP defaults to stateless; an explicit `MCP_SESSION_MODE` value still overrides it.
- **Tool argument rejections** now use typed `InvalidParams` envelopes with schema-derived recovery advice and client-visible reason text.
- **Environment configuration** treats empty strings and whole-value unsubstituted `${…}` placeholders as unset.
- **Argument key normalization** accepts `state_code` as `stateCode` when the canonical key is absent; unrelated unknown keys remain rejected.
- **Plugins and MCPB metadata** now expose `CONGRESS_API_KEY` as optional user configuration.
- **Development tooling and documentation** refresh the capability reference and contributor metadata, synchronize framework build and validation scripts, add CodeQL analysis, and include per-version changelogs in the npm package.

## Fixed

- **Upstream requests** preserve caller cancellation and non-retryable outcomes across Congress.gov documents, Congress.gov API calls, and Senate LIS votes.
- **Mirror lifecycle** stops scheduled refreshes and awaits cancellation before closing SQLite during teardown.
- **`congressgov_member_lookup` documentation** no longer advertises a nonexistent chamber filter ([#72](https://github.com/cyanheads/congressgov-mcp-server/issues/72)).
