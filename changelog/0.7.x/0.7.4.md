# 0.7.4 — 2026-10-10

## Changed

- **Tool argument repair** accepts numeric `congress`/`limit`/`offset` strings in committee-report listings, boolean `currentMember` strings in member listings, and `null` as an omitted optional `reportType` filter. Numeric-string repair applies to directly declared number fields, not values behind preprocessing.
- **Error correlation** adds a generated `data.requestId` matching the call's log records to framework-handled tool, resource, and prompt errors; rendered tool errors include the same ID. Protocol-level rejections and resource-parameter errors containing only `{ uri }` are excluded.
- **Document recovery** relies on declared hints instead of redundant forwards in the document service and selected report/Record handlers, preserving error codes, reasons, and recovery text on both client surfaces.
- **Development guidance** and checks sync with the framework; mirror CLI documentation specifies the checkout or Docker path mapping requirement, and logging examples include `LOG_LLM_INTERACTIONS`.

## Fixed

- **Docker builds** install target-platform production dependencies in a native build-platform stage, derive OTel installs from framework peer ranges, and remove musl-only packages from the glibc image.
- **Registry launches** use `npx` without npm-script arguments and fix `MCP_TRANSPORT_TYPE=http` for the HTTP package entry.
