# 0.7.0 — 2026-08-30

## Changed

- **Rendered HTML lists** now preserve item and following-paragraph boundaries in `content[]` while retaining the source HTML in structured results ([#58](https://github.com/cyanheads/congressgov-mcp-server/issues/58)).
- **Document `content[]`** now wraps exact structured text in a Markdown fence longer than any backtick run it contains ([#59](https://github.com/cyanheads/congressgov-mcp-server/issues/59)).
- **XML document extraction** now separates adjacent structural siblings while leaving inline tags and existing whitespace transparent; this intentionally changes `content` text, offsets, `nextOffset`, and total characters for no-`<pre>` XML documents ([#60](https://github.com/cyanheads/congressgov-mcp-server/issues/60)).
