# 0.4.3 — 2026-08-16

## Fixed

- **`congressgov_enacted_laws` list rows** now render the public/private law citation (`**Law:** Public Law 118-90`), shared by `lawCitations()` with bill lists and member sponsored/cosponsored legislation ([#45](https://github.com/cyanheads/congressgov-mcp-server/issues/45)).
- **Detail renderers no longer silently drop or cut off upstream data.** The member, roll-vote, senate-vote, and nomination detail formatters now fall through to `renderDetailRest` for any field outside their curated header set, and every hard cap on nested arrays (terms, leadership, nominees) and inline-string previews was removed — `renderInline` recurses into nested objects/arrays instead of truncating or JSON-stringifying them ([#50](https://github.com/cyanheads/congressgov-mcp-server/issues/50)).
- **Curated collection rows** (member terms, party history, leadership; nomination nominees) now append their own fields the curated line doesn't name, via a new `withUnnamedFields()` helper — found verifying #50, since the `renderDetailRest` fall-through only reaches a record's top level, not a collection the header renders itself.
- **`htmlToMarkdown()` boundary whitespace.** Emphasis spans (`<em>`/`<strong>`) are now matched and wrapped as whole units so a space inside the tag boundary (`<em>de minimis </em>treatment`) stays outside the Markdown marker instead of corrupting word spacing ([#51](https://github.com/cyanheads/congressgov-mcp-server/issues/51)).
- **`bill_lookup operation:"subjects"` now includes the policy area.** `extractSubjectItems()` emits it ahead of `legislativeSubjects[]`, each row tagged with a new `subjectType` field (`policyArea` | `legislativeSubject`) — previously dropped by `extractListItems()`'s single-array extraction, so pagination's advertised total exceeded what a caller could retrieve ([#47](https://github.com/cyanheads/congressgov-mcp-server/issues/47)).
- **`enacted_laws` `lawNumber` accepts the citation list rows actually carry.** `lawNumber` now takes either the bare integer or the compound `{congress}-{number}` citation (`"118-90"`), cross-checked against the supplied `congress` and normalized via `toLawNumber()` — removes the undocumented split-on-hyphen step between `list` and `get` ([#54](https://github.com/cyanheads/congressgov-mcp-server/issues/54)).
