# 0.5.0 — 2026-08-16

## Added

- **`content` operation** on `congressgov_bill_lookup`, `congressgov_committee_reports`, and `congressgov_daily_record` retrieves the actual document text behind their format URLs, one exact character window at a time (`characterOffset`/`characterLimit`, default 25,000, max 100,000) — pick a `format` (`text` or `xml`) and follow `nextOffset` to walk a whole document. Backed by a new `CongressDocumentsService` reaching `www.congress.gov` — a second host from the rest of the server, no API key, bounded by a 5,000,000-byte fetch ceiling, a 30s deadline, and host/content-type allowlists. Adds five error contracts: `document_unavailable`, `format_unavailable`, `document_fetch_failed`, `document_too_large`, `offset_past_end` ([#53](https://github.com/cyanheads/congressgov-mcp-server/issues/53)).

## Changed

- **`congressgov_legislative_research` prompt** now emits a discovery plan matching the deployment: with `CONGRESS_MIRROR_ENABLED` it routes through `congressgov_search_bills`; without it, it asks for a bill/member/committee/report seed instead of naming tools that can't filter by topic ([#52](https://github.com/cyanheads/congressgov-mcp-server/issues/52)).

## Fixed

- **List-row renderers no longer drop fields the curated line doesn't name.** New `withRowRest()`/`pick()` primitives in `format-helpers.ts` extend the existing completeness invariant from detail views to list rows — recovers values like a subcommittee row's `parent.systemCode` and a House vote row's `bioguideId` ([#55](https://github.com/cyanheads/congressgov-mcp-server/issues/55)).
- **`bill_lookup content` no longer serves the wrong version past the end of the list.** Congress.gov appends the enacted "Public Law" text version to every page, so an out-of-range `textVersionIndex` silently returned that row instead of failing — now decided from `pagination.count`.
- **`renderGenericItem` no longer drops `citation`/`bioguideId`/`systemCode`** when a row also carries a `type`+`number` pair.
- **`latestAction` rendering no longer drops `actionTime`** at the six sites that render it.
