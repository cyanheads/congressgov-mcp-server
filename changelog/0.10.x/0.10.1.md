# 0.10.1 — 2026-11-11

## Added

- **Search query notices** — a `congressgov_search_bills` query that used `NOT` or a word-initial `-` gets a notice saying how it was read and how to search the word instead (`"NOT"`, `covid-19`); an unmatched `(`, `)`, or `"` is ignored with a notice. ([#116](https://github.com/cyanheads/congressgov-mcp-server/issues/116))
- **`textVersionIndex` on `text` rows** of `congressgov_bill_lookup` and `congressgov_amendment_lookup` — the index `content` reads the version by, counted from the request `offset`. On a bill, an enrolled bill's undated Enrolled Bill version is 0 and an enacted bill's Public Law version is last. ([#124](https://github.com/cyanheads/congressgov-mcp-server/issues/124))
- **`fromDateTime`/`toDateTime` on `congressgov_committee_lookup`** — a window on the update dates of `bills` and `reports` rows; the other operations serve the pair with the ignored-input notice. ([#119](https://github.com/cyanheads/congressgov-mcp-server/issues/119))

## Changed

- **Error envelopes** no longer copy the upstream response `body` onto `structuredContent.error.data`.
- **`congressgov_search_bills` `query`** reads `AND`, `OR`, `NOT`, `-word`, `"phrase"`, `word*`, and parentheses as operators; 0.10.0 searched `OR`, `NOT`, and `-term` as words. ([#116](https://github.com/cyanheads/congressgov-mcp-server/issues/116))
- **`congressgov_crs_reports` `get`** pages `relatedMaterials` by the tool's `limit` (default 20) and `offset`, reporting `relatedMaterialsCount` and `relatedMaterialsNextOffset` when a page leaves rows out. ([#110](https://github.com/cyanheads/congressgov-mcp-server/issues/110))
- **Letter case** — `reportType` on `congressgov_committee_reports`, `lawType` on `congressgov_enacted_laws`, `billType` on `congressgov_bill_summaries` and `congressgov_search_bills`, `originChamber` on `congressgov_search_bills`, and `billType` on `congress://bill/{congress}/{billType}/{billNumber}` accept the case a row carries (`HRPT`, `PUB`, `HR`, `house`). ([#122](https://github.com/cyanheads/congressgov-mcp-server/issues/122))
- **Resource parameters** — `congress://member/{bioguideId}` and `congress://committee/{committeeCode}` accept any letter case, and the committee code may be percent-encoded.
- **`congressgov_legislative_research`** tells the model to pass a topic's keywords to `congressgov_search_bills` unquoted, since quotes now match the exact phrase. ([#116](https://github.com/cyanheads/congressgov-mcp-server/issues/116))
- **Scheduled mirror refresh** logs at `info`, not `error`, a run skipped because another sync holds the store's lease and a run that shutdown stopped.

## Fixed

- **`congressgov_search_bills` `invalid_query`**, the tool's first declared error, rejects a query of exclusions only (`-smoke`, `NOT smoke`), an `AND`, `OR`, or `NOT` with no term beside it, and more than 10 nested groups that hold `OR` or an exclusion. ([#116](https://github.com/cyanheads/congressgov-mcp-server/issues/116))
- **CRS `content` table cells** — a figure wrapped in a one-row table inside a cell (`$838`, `.2`) reads as that cell's content, so a data row stays one line; character offsets shift in reports whose cells open with a nested table. ([#118](https://github.com/cyanheads/congressgov-mcp-server/issues/118))
- **Text version paging** — a `text` walk across pages now reaches an enacted bill's Public Law version. ([#124](https://github.com/cyanheads/congressgov-mcp-server/issues/124))
- **Committee codes** resolve from the House, Senate, and joint committee lists, so codes whose prefix doesn't name their chamber (`jsat00`) and off-pattern codes (`n79043125`, `sp2k00`) read on `congressgov_committee_lookup` and `congress://committee/{committeeCode}`; with no `chamber`, `no94026591` (Senate Printing) resolves too. ([#113](https://github.com/cyanheads/congressgov-mcp-server/issues/113), [#114](https://github.com/cyanheads/congressgov-mcp-server/issues/114))
- **`congressgov_roll_votes` House `list`** orders by roll call number in both orders — `recent` latest vote first, `oldest` from roll call 1 — not by update date or upstream row order. ([#117](https://github.com/cyanheads/congressgov-mcp-server/issues/117))
- **`congressgov_member_lookup` `list` rows** print every service span on one `**Service:**` line (`House of Representatives, 1993–1995; Senate, 2001–present`) instead of the last span as Latest Term; a span or term with no `endYear` reads `start–present`, in `get` too. ([#123](https://github.com/cyanheads/congressgov-mcp-server/issues/123))
- **Mirror attempt timeout** — requests with no call context (the ingester and the `mirror:*` CLI) get 30 s an attempt, not 10 s, so one slow list page no longer fails the sync; the timeout message names the deadline that applied. ([#106](https://github.com/cyanheads/congressgov-mcp-server/issues/106))
- **Mirror resume** — `mirror:init` and `mirror:refresh` store a cursor with each page and resume after an interruption, skipping finished congresses; SIGINT/SIGTERM stop the sync after the request in flight and release its lease, so an immediate re-run resumes. ([#106](https://github.com/cyanheads/congressgov-mcp-server/issues/106))
- **Mirror CLI** is compiled to `dist/cli/`, so an npm install runs `mirror:*` under Bun or Node instead of failing to resolve `@/` imports; the image no longer writes a runtime `tsconfig.json` or copies `scripts/`. ([#107](https://github.com/cyanheads/congressgov-mcp-server/issues/107))
