# 0.10.0 — 2026-11-03

Breaking: `list` on three tools, two ID fields, `committeeCode`, and committee name resolution within `chamber` now reject inputs 0.9.1 answered.

## Added

- **`congressgov_amendment_lookup`** — `list`, `get`, `actions`, `cosponsors`, `amendments`, `text`, and `content` for House (`hamdt`), Senate (`samdt`), and Senate unprinted (`suamdt`, 97th–98th) amendments, keyed by `congress` + `amendmentType` (any letter case) + `amendmentNumber`. ([#100](https://github.com/cyanheads/congressgov-mcp-server/issues/100))
- **`rollVote` on `actions` rows** of `congressgov_bill_lookup` and `congressgov_amendment_lookup` — the `congressgov_roll_votes` arguments for the one roll call the row records (House from the 115th Congress, Senate from the 101st). ([#102](https://github.com/cyanheads/congressgov-mcp-server/issues/102))
- **`congressgov_roll_votes` `members` filters** — `bioguideId` (House only; a Senate call fails `unsupported_filter`), `stateCode`, and `party` apply before paging; `pagination.count` counts the matches and `memberFilter.rosterCount` the full roster. ([#102](https://github.com/cyanheads/congressgov-mcp-server/issues/102))
- **Voteview fallback for Senate votes** — `congressgov_roll_votes` serves Senate `list`, `get`, and `members` from Voteview when the LIS feed can't be read, with `source` (URL, latest vote, citation) on both surfaces. A vote past Voteview's latest is `not_found`, a Voteview 429 is `rate_limited` and not retried, and a truncated body is `upstream_error`. ([#90](https://github.com/cyanheads/congressgov-mcp-server/issues/90))
- **`congressgov_crs_reports` `content`** — reads a report's HTML version as plain text in `characterOffset`/`characterLimit` windows; a report with only a PDF fails `format_unavailable` naming its URL. ([#101](https://github.com/cyanheads/congressgov-mcp-server/issues/101))
- **`part` and `parts` on `congressgov_committee_reports`** — `get`, `text`, and `content` serve Part 1 unless `part` names another, and a multi-part report lists its parts in `parts`. A missing part is `not_found` naming the parts that exist; `list` rejects `part` as `incompatible_identity`. ([#95](https://github.com/cyanheads/congressgov-mcp-server/issues/95))
- **Update-date filters** — `fromDateTime`/`toDateTime` on `list` for `congressgov_crs_reports`, `congressgov_senate_nominations`, and `congressgov_committee_reports`, plus `conference` on committee reports. ([#103](https://github.com/cyanheads/congressgov-mcp-server/issues/103))
- **`mirroredCongresses` on `congressgov_search_bills`** — every response lists the congresses the mirror holds; a `congress` outside them returns an empty result with a notice pointing at `congressgov_bill_lookup`. ([#99](https://github.com/cyanheads/congressgov-mcp-server/issues/99))

## Changed

- **`list` refuses identities it ignored** — `congressgov_member_lookup` (`bioguideId`), `congressgov_enacted_laws` (`lawNumber`), and `congressgov_committee_lookup` (`committeeCode`) fail with `incompatible_identity` before any request, including alongside the operation's own filters. ([#97](https://github.com/cyanheads/congressgov-mcp-server/issues/97))
- **`committeeCode`** must contain an ASCII letter or digit; a value without one, such as `..`, fails validation. ([#97](https://github.com/cyanheads/congressgov-mcp-server/issues/97))
- **Committee name resolution** — `congressgov_committee_lookup` resolves a name given with `chamber` within that chamber only: a name found only in another chamber no longer resolves, and a lone approximate match comes back as a candidate. A resolved name is fetched in its roster row's chamber. ([#108](https://github.com/cyanheads/congressgov-mcp-server/issues/108))
- **Ignored-input notices** — an input an operation doesn't use is served and named in `notice`, joined with "or": `congress`, `stateCode`, `district`, and `currentMember` on `congressgov_member_lookup`; `congress` and `filter` on `congressgov_committee_lookup`; `fromDateTime`/`toDateTime` outside `list`. ([#97](https://github.com/cyanheads/congressgov-mcp-server/issues/97), [#103](https://github.com/cyanheads/congressgov-mcp-server/issues/103))
- **Summary pages** — `congressgov_bill_summaries` and `congressgov_bill_lookup` `summaries` return `limit` rows; the page character budget and its notice are gone, and the per-row text window is unchanged. ([#98](https://github.com/cyanheads/congressgov-mcp-server/issues/98))
- **`congressgov_roll_votes` `chamber`** accepts any letter case. ([#102](https://github.com/cyanheads/congressgov-mcp-server/issues/102))
- **Bill action rows** print the source system's code beside its name in `content[]`.
- **Mirror store spec** — moves to `version: 3`; its migration clears the checkpoint, so the next `mirror:refresh` re-walks every configured congress from its start. ([#92](https://github.com/cyanheads/congressgov-mcp-server/issues/92), [#104](https://github.com/cyanheads/congressgov-mcp-server/issues/104))

## Fixed

- **Mirror bill walk** — `mirror:init` and `mirror:refresh` no longer page the bill list by offset, which skipped and repeated bills inside update-time ties; each bill the list reports is stored once, and a failed run leaves the checkpoint unchanged. ([#92](https://github.com/cyanheads/congressgov-mcp-server/issues/92))
- **Mirror backfill** — a congress added to `CONGRESS_MIRROR_CONGRESSES` is walked from its start on the next `mirror:refresh`. ([#104](https://github.com/cyanheads/congressgov-mcp-server/issues/104))
- **`./.env` under Node** — `CONGRESS_API_KEY`, `CONGRESS_MIRROR_ENABLED`, and the other server variables in `./.env` apply as under Bun, without overriding set variables. ([#105](https://github.com/cyanheads/congressgov-mcp-server/issues/105))
- **Congress ordinals** — echoes, notices, vote headers, and both prompts print `102nd Congress`, not `102th`. ([#94](https://github.com/cyanheads/congressgov-mcp-server/issues/94))
- **ID patterns** — `nominationNumber` accepts `1000`, `730-2`, or either with a `PN` prefix; the CRS `reportNumber` accepts letters then digits (`R40097`) or two digit groups joined by a hyphen (`96-548`). Case and surrounding whitespace are ignored; any other form, including `?`, `#`, `/`, embedded whitespace, percent-encoding, and non-ASCII digits, is `invalid_arguments`. ([#96](https://github.com/cyanheads/congressgov-mcp-server/issues/96))
- **House votes before the 115th** — `congressgov_roll_votes` `get` and `members` fail `not_found` before any request, naming Congress.gov's coverage and the Clerk's vote XML in a bill action's `recordedVotes`. ([#109](https://github.com/cyanheads/congressgov-mcp-server/issues/109))
- **Committee chamber** — `congressgov_committee_lookup` reads a code its prefix's chamber doesn't hold (`jsat00`) in the roster's chamber, and accepts `chamber` in any letter case. ([#111](https://github.com/cyanheads/congressgov-mcp-server/issues/111), [#112](https://github.com/cyanheads/congressgov-mcp-server/issues/112))
