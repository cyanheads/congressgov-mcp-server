# 0.6.0 — 2026-08-30

## Changed

- **`tools/list` output schemas** now declare every non-list result root while retaining permissive nested Congress.gov records ([#64](https://github.com/cyanheads/congressgov-mcp-server/issues/64)).
- **Tool titles** now use explicit `Congress.gov` branding, preserve `CRS`, and omit internal committee-filter implementation details ([#65](https://github.com/cyanheads/congressgov-mcp-server/issues/65)).
- **`congressgov_search_bills.query`** now requires at least one Unicode letter or number and rejects tokenless searches at the MCP boundary ([#61](https://github.com/cyanheads/congressgov-mcp-server/issues/61)).
- **`congressgov_member_lookup` identifiers** now validate Bioguide IDs as one ASCII letter plus six digits and state codes as two ASCII letters ([#66](https://github.com/cyanheads/congressgov-mcp-server/issues/66)).

## Fixed

- **List formatters** now preserve list rendering when results also carry named document-content metadata.

- `fast-xml-parser` `^5.11.0` → `^5.11.1`
- `@biomejs/biome` `^2.5.10` → `^2.5.11`
